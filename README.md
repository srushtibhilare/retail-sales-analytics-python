📊 Retail Demand & Pricing Analytics

Objective:
Analyze pricing, promotions, and customer behavior to derive actionable business insights.

Tools:
Python, Pandas, NumPy, SQL (SQLite), Matplotlib, Seaborn

Key Analysis:
- Data cleaning & feature engineering
- Exploratory data analysis
- Statistical hypothesis testing
- SQL-based business queries
- Visualization & reporting

Key Insights:
- Discounts increase demand but raise return risk
- Customer sentiment significantly impacts returns
- Competitive pricing is critical for footfall

Outcome:
Provided data-driven recommendations for pricing and marketing optimization.
